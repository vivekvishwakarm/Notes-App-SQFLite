# Note App

## Overview
The **Note App** is a simple, yet efficient note-taking application built using the Flutter framework. This app provides essential functionality for creating, reading, updating, and deleting (CRUD) notes, along with a powerful search feature. The app leverages **SQFLite** for local data storage, ensuring that all notes are stored securely on the device, even in offline mode.

## Features
- **CRUD Operations**:
  - **Create** new notes with titles and descriptions.
  - **Read** and view all stored notes in an intuitive list format.
  - **Update** existing notes with new information.
  - **Delete** notes that are no longer needed.
- **Search Functionality**: 
  - Easily search through notes by keywords or phrases to find the specific note you're looking for.
- **Responsive UI**:
  - Adaptable UI that adjusts seamlessly to different screen sizes, offering an optimal user experience across all devices.

## Tech Stack
- **Frontend**: Flutter Framework (Dart)
- **Database**: SQFLite (SQLite)
- **State Management**: Provider (optional for state management, adjust based on your implementation)
