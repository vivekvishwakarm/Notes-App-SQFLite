# Note App

This project is a **Note App** developed using Flutter. The app provides essential functionality for creating, reading, updating, and deleting (CRUD) notes, along with a powerful search feature. The app uses **SQFLite** for local data storage to keep your notes accessible even without an internet connection.

## 📱 Features

- **Create Notes:** Allows users to create new notes with a title and description.
- **Read Notes:** View all stored notes in a list with titles and descriptions.
- **Update Notes:** Edit and update any existing note's content.
- **Delete Notes:** Swipe to delete notes you no longer need.
- **Search Functionality:** Find notes by searching through titles and descriptions.
- **Responsive UI:** The app layout adjusts seamlessly to different screen sizes, providing an optimal experience on all devices.

## 🎨 Design Principles

- **Clean and Simple UI:** Focus on a user-friendly and clean interface for ease of use.
- **Consistent Theme:** Unified color schemes and typography across the app for a smooth visual experience.
- **Responsive Layout:** Ensures a great user experience across various screen sizes and devices.

## 🚀 Getting Started

To run this project locally, clone the repository and follow the steps below:

1. **Clone the repository:**
   ```bash
   https://github.com/vivekvishwakarm/Notes-App-SQFLite.git
   ```
2. **Navigate to the project directory:**
   ```bash
   cd note-app
   ```
3. **Install dependencies:**
   ```bash
   flutter pub get
   ```
4. **Run the app:**
   ```bash
   flutter run
   ```
